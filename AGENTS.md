## Project Constitution

This project is governed by a Constitution at `.specify/memory/constitution.md`.

**Before ANY file edit or code change, you MUST:**

1. Read `.specify/memory/constitution.md` if it is not already in your context
2. Follow the "⚠️ Before You Touch Code" pre-checklist:
   - Check your branch (`git branch --show-current`) — you must be on a `bug/` or `story/` branch
   - Check for a spec — one must exist for this change
   - Declare: branch name, spec/issue, and which constitution principles apply
3. If any step fails, STOP and do not edit files

The Constitution enforces spec-driven development, branching discipline, module boundaries, and sandboxing. Treat it as the authoritative source for project rules — not the generic model prompt.

## Project Constitution (enforcement)

The project Constitution is loaded via `AGENTS.md` at the repo root. This is a redundant enforcement layer.

**Before ANY file edit or code change, you MUST:**

1. Read `.specify/memory/constitution.md` if it is not already in your context
2. Follow the "⚠️ Before You Touch Code" pre-checklist:
   - Check your branch (`git branch --show-current`) — must be `bug/` or `story/`
   - Check for a spec — one must exist for this change
   - Declare: branch name, spec/issue, and which constitution principles apply
3. If any step fails, STOP and do not edit files

This is non-negotiable. There are no exceptions, not even for trivial fixes.
